# GrapeOS на реальному ПК

Для **UEFI / ASUS TUF Dash F15 2022** дивись
[окрему інструкцію](uefi-asus.md) та використовуй `grapeos-uefi.img`.
Нижче описано стару BIOS/Legacy-версію `grapeos-usb.img`.

## Сумісність

Це пробна BIOS/Legacy-версія для x86 (Intel/AMD, також 64-бітний процесор
із 32-бітним protected mode). Потрібні:

- BIOS або ввімкнений Legacy/CSM з USB-HDD boot та BIOS EDD.
- VGA-сумісна відеокарта: текстовий режим і 640×480, 16 кольорів.
- Клавіатура PS/2 або вбудована клавіатура з контролером i8042. USB-клавіатура
  може працювати через USB Legacy Support прошивки; її робота після
  переходу в ядро залежить від прошивки. Власного USB HID драйвера ще немає.
- Флешка від 32 МіБ; для перевірок у QEMU використовується 32 МіБ RAM.

ПК з UEFI без CSM потребує нового `grapeos-uefi.img`, а не цього
BIOS-образу. Миша наразі не підтримується.
Завантаження з USB й IDE перевірено в QEMU/SeaBIOS; фізичного ПК для
перевірки в цій роботі не було.

## Образ і попередня перевірка

```sh
cd "/home/xiaomi2009user/Документи/grapeos"
make usb
./run.sh --usb
```

Файл для запису — `build/grapeos-usb.img`. Контрольна сума:

```sh
cd build
sha256sum -c grapeos-usb.img.sha256
```

Для запуску GUI введи `gui` після налаштування. Ctrl+N — блокнот,
Ctrl+T — термінал, Ctrl+S — збереження нотатки для поточної сесії.
Escape повертає з програми на стіл, а зі столу в текстову оболонку.

## Запис на флешку в Linux

Запис образу **стирає попередні дані на вибраній флешці**. Використай
окрему флешку без потрібних файлів. Внутрішній SSD/HDD не є ціллю запису.

1. Підключи флешку й визнач її за розміром, моделлю та `TRAN=usb`:

   ```sh
   lsblk -o NAME,SIZE,MODEL,TRAN,MOUNTPOINTS
   ```

2. Відмонтуй її розділи через файловий менеджер. Для запису використай
   програму запису raw `.img` або команду нижче. Заміни `/dev/sdX` на
   **весь пристрій флешки**, наприклад `/dev/sdb`, а не розділ `/dev/sdb1`:

   ```sh
   sudo dd if="/home/xiaomi2009user/Документи/grapeos/build/grapeos-usb.img" of=/dev/sdX bs=4M status=progress conv=fsync
   ```

3. Після завершення безпечно витягни флешку. Перенеси її на потрібний ПК
   та відкрий його boot menu. Клавіша меню залежить від моделі ПК.
4. Вибери завантаження флешки через **Legacy/BIOS**, за потреби ввімкни
   Legacy/CSM і USB Legacy Support у налаштуваннях прошивки.
5. З’явиться **GrapeLoad**. Натисни Enter на **GrapeOS**, дочекайся логів,
   пройди перше налаштування й введи `gui` або `help`.

## Що зберігається

USB-образ працює в RAM: профіль, нотатки, список установлених програм і
рекорд гри зникають після перезапуску. ОС повідомляє про session mode.
Всі застосунки вбудовані; `Grapemarket -I snake` вмикає гру без інтернету.

Для USB-завантаження ядро пропускає весь драйвер ATA, включно з
IDENTIFY, читанням і записом. Внутрішні диски ПК не використовуються.
FAT16-розділ містить лише README; ядро не використовує його як сховище.
Звичайний запуск `./run.sh` у QEMU зберігає дані на окремому
`data/grapeos-data.img`, як раніше.

## Якщо не працює

- Флешки немає в boot menu: перевір режим Legacy/CSM та запис образу
  на весь USB-пристрій. Не копіюй `.img` як звичайний файл.
- `GrapeLoad needs BIOS EDD / USB-HDD mode`: прошивка не надала EDD.
  Перевір USB-HDD замість USB-FDD у її налаштуваннях.
- Enter працює в GrapeLoad, але не в ОС: спробуй PS/2 або вбудовану
  клавіатуру; USB Legacy Support може бути недостатньо для цього ядра.
- Командна оболонка працює, а `gui` не показує картинку: відеокарта може
  не підтримувати пряме програмування VGA. Потрібен окремий відеодрайвер.
