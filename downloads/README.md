# Готова GrapeOS

`grapeos-desktop.zip` містить чистий USB-образ UEFI x86-64, EFI-файл
та інструкцію. Він зібраний з вихідників цього репозиторію й не містить
особистих документів або профілю користувача.

Контрольна сума ZIP — у `SHA256SUMS`. У Linux:

```sh
cd downloads
sha256sum -c SHA256SUMS
```

Для оновлення наявної флешки GrapeOS розпакуй ZIP і скопіюй
`EFI/BOOT/BOOTX64.EFI` на те саме місце на флешці. Папку `GRAPE` збережи.
Повний запис USB-образу перезаписує вміст вибраної флешки.
